# FLUXO KDS — REALIDADE DE COZINHA BRASILEIRA

## VISÃO GERAL NO SETOR

A cozinha brasileira real é um ambiente quente, barulhento e de ritmo acelerado. O KDS (tela digital) está presente em ~30% dos restaurantes. O restante usa **impressora térmica** na cozinha (a comanda de papel cai na bancada). A realidade é híbrida:

```
  REALIDADE DA COZINHA BRASILEIRA:

  ┌─────────────────────────────────────────────────────────┐
  │  COZINHA PEQUENA (60%):                                 │
  │  • Impressora térmica na cozinha (comanda de papel)     │
  │  • Papel cai na bancada, cozinheiro prepara             │
  │  • Garçom grita "SAIU!" quando o prato sai             │
  │  • Sem tela, sem timer, sem tecnologia                 │
  └─────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────┐
  │  COZINHA MÉDIA (30%):                                   │
  │  • Impressora térmica + tela KDS                        │
  │  • Papel cai e ao mesmo tempo aparece na tela           │
  │  • Timer na tela, mas cozinheiro ignora                 │
  │  • Garçom usa sineta ou grito para "prato pronto"       │
  └─────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────┐
  │  COZINHA GRANDE / REDE (10%):                           │
  │  • KDS 100% digital (sem papel)                         │
  │  • Estações separadas: grill, fritas, saladas, bar      │
  │  • Timer + cores + som + SLA                            │
  │  • Sineta eletrônica (luz + som) quando pronto          │
  └─────────────────────────────────────────────────────────┘
```

## 1. O PAPEL AINDA REINA (E POR QUÊ)

### 1.1 Por que a impressora térmica ainda domina

| Motivo | Explicação |
|--------|------------|
| **Custo** | Impressora térmica: R$ 400. Tablet KDS: R$ 1.500+ |
| **Resistência** | Papel não quebra com gordura, água, calor. Tablet sim. |
| **Simplicidade** | Cozinheiro lê o papel, prepara, joga fora. Sem interação. |
| **Velocidade** | Papel cai instantâneo. Tela pode ter lag. |
| **Garantia** | Com papel, o pedido está físico — não há "sumiu da tela" |

### 1.2 Configuração mais comum no Brasil

```
  ┌────────────────────────────────────────────────────┐
  │  COZINHA — SETUP TÍPICO                           │
  │                                                    │
  │  ┌──────────┐          ┌──────────┐               │
  │  │ IMP.     │          │ KDS      │               │
  │  │ TÉRMICA  │          │ (tela)   │               │
  │  │ (papel)  │          │ (opcional)│               │
  │  └──────────┘          └──────────┘               │
  │       │                     │                      │
  │       ▼                     ▼                      │
  │  ┌──────────────────────────────────┐              │
  │  │  BANCADA DO COZINHEIRO          │              │
  │  │  • Lê o papel                   │              │
  │  │  • Prepara                      │              │
  │  │  • Bota no balcão               │              │

  └────────────────────────────────────────────────────┘
```

## 2. FLUXO REAL NA COZINHA

### 2.1 Fluxo com impressora térmica (padrão)

```
  GARÇOM LANÇA PEDIDO NO TABLET
       │
       ▼
  ┌─────────────────────────────────────────┐
  │  IMPRESSORA TÉRMICA NA COZINHA         │
  │  Imprime comanda:                      │
  │  ┌────────────────────────────────┐    │
  │  │ MESA 5 — 19:45                │    │
  │  │ ──────────────────────────    │    │
  │  │ 2x Filé c/ fritas            │    │
  │  │   Obs: mal passado           │    │
  │  │ 1x Salada Caesar             │    │
  │  │ ──────────────────────────    │    │
  │  │ Garçom: João                 │    │
  │  └────────────────────────────────┘    │
  │                                        │
  │  (opcional: mesma comanda no KDS)     │
  └─────────────────────────────────────────┘
       │
       ▼
  ┌─────────────────────────────────────────┐
  │  COZINHEIRO:                            │
  │  • Pega o papel                         │
  │  • Prepara os pratos                    │
  │  • Coloca no balcão de passagem        │
  │  • Bota o papel em cima do prato        │
  │    (para o garçom identificar)          │
  │  • Grita "MESA 5 PRONTO!"              │
  └─────────────────────────────────────────┘
       │
       ▼
  ┌─────────────────────────────────────────┐
  │  GARÇOM:                                │
  │  • Escuta o grito                       │
  │  • Pega o prato + confere o papel       │
  │  • Leva à mesa                          │
  │  • No tablet: marca como "servido"      │
  │    (ou apenas entrega e pronto)         │
  └─────────────────────────────────────────┘
```

### 2.2 KDS como complemento, não substituto

```
  O KDS NÃO SUBSTITUI A IMPRESSORA — complementa

  Benefícios do KDS mesmo com impressora:
  • Visão geral de todos os pedidos pendentes
  • Timer para saber há quanto tempo está esperando
  • Cor vermelha para pedidos atrasados
  • Estatísticas de tempo médio de preparo
  • Gestor consegue ver gargalos
```

## 3. ESTAÇÕES DE COZINHA

### 3.1 Divisão real

| Estação | Itens | Impressora separada? | KDS separado? |
|---------|:-----:|:-------------------:|:-------------:|
| **Cozinha geral** | Carnes, massas, petiscos | ✅ 1 impressora | ✅ 1 tela |
| **Fritas** | Batata frita, pastel, Coxinha | ⚠️ Mesma da cozinha | ⚠️ Mesma tela |
| **Saladas/Sobremesas** | Saladas, doces | ❌ Mesma | ❌ Mesma |
| **Bar** | Bebidas, sucos, drinks | ✅ 1 impressora | ✅ 1 tela |
| **Churrasqueira** | Carnes no espeto | ✅ 1 impressora (opcional) | ✅ 1 tela |

### 3.2 Na prática: 2 estações resolve 90% dos restaurantes

```
  ┌──────────────────────┐    ┌──────────────────────┐
  │   COZINHA            │    │   BAR                │
  │                      │    │                      │
  │  Impressora          │    │  Impressora          │
  │  (opcional: KDS)     │    │  (opcional: KDS)     │
  │                      │    │                      │
  │  Itens:              │    │  Itens:              │
  │  • Carnes            │    │  • Refrigerantes     │
  │  • Massas            │    │  • Sucos             │
  │  • Petiscos          │    │  • Drinks            │
  │  • Sobremesas        │    │  • Águas             │
  │  • Porções           │    │  • Cervejas          │
  └──────────────────────┘    └──────────────────────┘
```

## 4. TEMPO E SLA — REALIDADE

### 4.1 Tempos reais de preparo

| Item | Tempo médio |
|------|:-----------:|
| Bebidas (garrafa/lata) | 30 seg |
| Bebidas (coquetel/drink) | 3-5 min |
| Porções (fritas) | 8-12 min |
| Prato quente (filé, massa) | 15-25 min |
| Grelhados (picanha) | 20-30 min |
| Pizza | 15-20 min |
| Sobremesa simples (petit gateau) | 5-8 min |

### 4.2 SLA realista

```
  🟢 Verde: até o tempo médio do item
  🟡 Amarelo: tempo médio + 5 min
  🔴 Vermelho: tempo médio + 10 min
  ⚫ Preto: mais que o dobro do tempo médio

  ⚠️ SLA no restaurante real é INFORMATIVO
     Cozinheiro não acelera por causa do timer
     Timer serve para o GESTOR identificar gargalos
```

## 5. SOM E SINALIZAÇÃO

### 5.1 Sineta eletrônica (prato pronto)

```
  ┌─────────────────────────────────────────┐
  │  BALCÃO DE PASSAGEM — PRATOS PRONTOS   │
  │                                         │
  │  ┌─────────────────────────────────┐   │
  │  │  🔴 SINETA                      │   │
  │  │  (botão no balcão)              │   │
  │  │                                 │   │
  │  │  Cozinheiro aperta quando       │   │
  │  │  o prato está no balcão         │   │
  │  │                                 │   │
  │  │  Luz pisca + som toca no salão │   │
  │  │  Garçom olha qual mesa          │   │
  │  │  (pelo papel em cima do prato)  │   │
  │  └─────────────────────────────────┘   │
  │                                         │
  │  Se KDS: mesmo botão pode ser          │
  │  digital (clicar "Pronto" no KDS        │
  │  acende a sineta)                       │
  └─────────────────────────────────────────┘
```

### 5.2 Notificação no tablet do garçom

```
  Quando KDS marca "pronto":
  → Notificação PUSH no tablet do garçom
  → "Mesa 5 — Filé c/ fritas está pronto"
  → Garçom não precisa ficar olhando o balcão
```

## 6. CONFIGURAÇÃO RECOMENDADA

### 6.1 Por porte

```
  RESTAURANTE PEQUENO:
  ├── 1 impressora térmica na cozinha (ESC/POS)
  ├── 1 impressora térmica no bar (se houver)
  ├── SEM KDS (desnecessário)
  └── Sineta eletrônica no balcão (R$ 50)

  RESTAURANTE MÉDIO:
  ├── 1 impressora térmica na cozinha
  ├── 1 KDS na cozinha (opcional)
  ├── 1 impressora térmica no bar
  ├── 1 KDS no bar (opcional)
  └── Notificação push no tablet do garçom

  REDE / GRANDE:
  ├── KDS em todas as estações
  ├── Impressoras de backup (papel ainda é garantia)
  ├── Sineta eletrônica + notificação push
  └── Painel de gestão com SLA e métricas
```

## 7. REGRAS DE NEGÓCIO — REAIS

| # | Regra |
|---|-------|
| 1 | Impressora térmica é PRIORIDADE — KDS é complemento |
| 2 | Cozinha comanda de papel não tem "aceitar" — o papel já caiu, já está na bancada |
| 3 | SLA timer é INFORMATIVO para gestão — cozinheiro não interage com ele |
| 4 | Som de "novo pedido" na cozinha = impressora imprimindo (ninguém precisa de som digital) |
| 5 | Cada estação (cozinha/bar) tem sua própria impressora — itens roteados automaticamente |
| 6 | Bebidas NUNCA vão para a impressora da cozinha (só do bar) |
| 7 | Garçom não precisa marcar "servido" no sistema se o fluxo for manual |
| 8 | KDS serve mais ao GESTOR do que ao cozinheiro (métricas, gargalos) |
| 9 | Pedido cancelado já impresso: cozinha DEVE ser avisada (grito ou KDS) |
| 10 | Impressora falhou? Pedido continua na tela KDS (se houver) — nunca perde o pedido |

## 8. MODELO DE CONFIGURAÇÃO

```javascript
{
  kdsConfig: {
    enabled: Boolean,                 // KDS ativo?
    soundUrl: String,                 // Som para novo pedido
    stations: [{                      // Estações
      name: String,                   // cozinha | bar | dessert
      displayName: String,            // "Cozinha" | "Bar"
      printers: [ObjectId],           // Impressoras da estação
      kdsScreen: Boolean              // Tem tela KDS?
    }],
    printer: {
      enabled: Boolean,               // Impressão automática?
      paperSize: String,              // 80mm | 58mm
      cutOnFinish: Boolean,           // Cortar papel ao final?
      printObservations: Boolean,     // Imprimir observações?
      printOrderNumber: Boolean       // Imprimir número do pedido?
    },
    sla: {
      warningMinutes: 10,
      criticalMinutes: 15
    }
  }
}
```

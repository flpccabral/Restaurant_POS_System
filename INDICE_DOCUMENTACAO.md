## 📝 Convenções de Nomenclatura

### Documentos

- **Maiúsculas**: DOCUMENTACAO_TECNICA.md, README.md, CHANGELOG.md
- **Prefixo FLUXO_**: FLUXO_PEDIDO.md, FLUXO_CAIXA.md, etc.
- **Docs folder**: Docs/revisao-*.md, Docs/autossuficiencia-*.md

### Seções

- **Títulos**: # Título Principal
- **Subtítulos**: ## Subtítulo
- **Sub-subtítulos**: ### Sub-subtítulo

### Código

- **Inline**: `codigo`
- **Blocos**: ```javascript ... ```
- **Comentários**: // Comentário ou /* Comentário */

## 🔗 Links Rápidos

### Instalação Rápida

```bash
# Backend
cd pos-backend && npm install && cp .env.example .env

# Frontend
cd pos-frontend && npm install && cp .env.example .env

# MongoDB
mongod --dbpath /data/db

# Popular banco
cd pos-backend && npm run seed

# Iniciar
# Terminal 1: cd pos-backend && npm run dev
# Terminal 2: cd pos-frontend && npm run dev
```

### Teste Rápido

```bash
# Backend
curl http://localhost:5000/api/health

# Frontend
# Acesse http://localhost:5173
```
